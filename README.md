# ♟ Шахматы

Простой, но полностью рабочий MVP веб-приложения «Шахматы»: игра против
компьютера и сетевая игра с другим человеком без регистрации и авторизации.
Сетевая игра построена на lobby со списком онлайн-игроков и приглашениях —
без кодов комнат.

## Стек технологий

**Backend**
- Java 21
- Spring Boot 4 (Spring WebSocket, без Spring Web MVC REST — всё общение в
  реальном времени)
- Maven
- Без базы данных — всё состояние хранится в памяти процесса
  (`ConcurrentHashMap` для подключённых пользователей и игровых партий)
- Собственный шахматный движок на чистой Java (полные правила: рокировка,
  взятие на проходе, превращение пешки, шах/мат/пат, ничьи) — используется
  как единственный источник истины для сетевой игры

**Frontend**
- React 19 + TypeScript
- Vite (dev-сервер слушает все сетевые интерфейсы — доступен по LAN IP)
- `chess.js` — правила и генерация ходов для локальной игры с компьютером
- `react-chessboard` — отрисовка доски
- `react-router-dom` — навигация между экранами

## Требования

- **Java 21+** (JDK)
- **Node.js 20+** и npm
- Maven не обязателен — используйте `./mvnw` (Maven Wrapper)

## Запуск Backend

```bash
cd chesszimka
./mvnw spring-boot:run
```

Backend поднимется на `http://localhost:8080` (единственная точка входа —
WebSocket `/ws/app`, REST API не используется).

## Запуск Frontend

В отдельном терминале:

```bash
cd chesszimka/frontend
npm install
npm run dev
```

Frontend поднимется на `http://localhost:5173` и настроен через Vite proxy
(`vite.config.ts`) так, чтобы WebSocket-соединения `/ws/**` прозрачно
проксировались на backend (`http://localhost:8080`). Dev-сервер Vite слушает
все сетевые интерфейсы (`server.host: true`), поэтому приложение доступно и
по IP компьютера в локальной сети (Vite выводит адрес при запуске, например
`http://192.168.1.23:5173`).

Frontend никогда не обращается к `localhost` напрямую — адрес WebSocket
backend вычисляется на лету из `window.location.host`, поэтому один и тот же
собранный фронтенд одинаково работает и через `localhost`, и через LAN IP.

## Открыть приложение

Откройте в браузере:

```
http://localhost:5173
```

Либо (для игры по локальной сети с другого компьютера) адрес, который Vite
вывел в консоли как `Network:`, например `http://192.168.1.23:5173`.

## Как играть

### Игра с компьютером

1. На главном экране введите имя (или оставьте поле пустым — вам будет
   присвоено случайное смешное имя, например «Конь в пальто»).
2. Нажмите **«Играть с компьютером»**.
3. Выберите цвет: белые, чёрные или случайно.
4. Нажмите **«Начать партию»** — доска откроется, и вы сможете играть.
   Компьютер отвечает легальными ходами с небольшой задержкой (0.5–1.4 c).

### Сетевая игра (два игрока, через lobby и приглашения)

1. На главном экране введите имя и нажмите **«Играть по сети»** — вы
   попадёте в lobby со списком игроков, готовых играть прямо сейчас.
2. Второй игрок открывает приложение (тот же адрес — `localhost` или LAN IP)
   на другом устройстве/вкладке/браузере, тоже вводит имя и нажимает
   **«Играть по сети»**.
3. Оба игрока сразу видят друг друга в списке «Игроки онлайн».
4. Любой из игроков нажимает **«Играть»** напротив имени соперника — тому
   приходит всплывающее приглашение с кнопками «Принять» / «Отклонить».
5. После принятия backend создаёт партию, случайным образом назначает
   цвета, и оба клиента автоматически переходят на экран одной и той же
   шахматной партии.
6. Все ходы проверяются и подтверждаются backend'ом через WebSocket — сервер
   является единственным источником истины, нелегальные ходы и ходы не в
   свою очередь отклоняются.
7. Если соперник закрывает вкладку или временно теряет соединение, у него
   есть ~10 секунд на переподключение (при обновлении страницы состояние
   партии восстанавливается автоматически); если он не вернулся — второй
   игрок увидит сообщение «Соперник отключился», и партия завершается.

### Как подключить второго игрока (пошагово)

1. Запустите backend и frontend (см. выше).
2. Откройте `http://localhost:5173` в первом браузере — это игрок 1.
3. Откройте это же приложение во втором браузере (или на другом компьютере
   в той же сети — по LAN IP, который вывел Vite) — это игрок 2.
4. Оба вводят имя (или используют автосгенерированное) и жмут «Играть по
   сети».
5. Игрок 1 видит игрока 2 в списке и нажимает «Играть».
6. Игрок 2 видит всплывающее приглашение и нажимает «Принять».
7. Оба автоматически оказываются на одной шахматной доске с разными
   цветами и играют в реальном времени.

## WebSocket-протокол

Единственная точка входа: `ws://<host>/ws/app?clientId=<uuid>&name=<имя>`.

`clientId` — стабильный идентификатор клиента, генерируется один раз на
frontend (`crypto.randomUUID()`) и хранится в `localStorage`, что позволяет
переподключаться под тем же идентификатором после разрыва соединения или
перезагрузки страницы.

Клиент → сервер:
- `{"type":"INVITE","targetId":"..."}` — пригласить игрока
- `{"type":"ACCEPT_INVITE","fromId":"..."}` — принять приглашение
- `{"type":"DECLINE_INVITE","fromId":"..."}` — отклонить приглашение
- `{"type":"CANCEL_INVITE","targetId":"..."}` — отменить своё приглашение
- `{"type":"RENAME","name":"..."}` — изменить имя
- `{"type":"MOVE","gameId":"...","from":"e2","to":"e4","promotion":"q"}` — сделать ход

Сервер → клиент:
- `{"type":"LOBBY_LIST","players":[{"id":"...","name":"..."}]}` — актуальный список готовых играть (без вас самих)
- `{"type":"INVITATION","fromId":"...","fromName":"..."}` — входящее приглашение
- `{"type":"INVITE_DECLINED"|"INVITE_CANCELLED","byId":"...","byName":"..."}` — приглашение завершилось без игры
- `{"type":"GAME_STARTED","gameId":"...","yourColor":"WHITE"|"BLACK"}` — партия создана
- `{"type":"GAME_STATE", "gameId":"...", "fen":"...", "turn":"WHITE", "status":"IN_PROGRESS"|"FINISHED", ...}` — полное состояние партии
- `{"type":"ERROR","message":"..."}` — ошибка (недопустимый ход, чужая очередь и т.д.)

## Правила

Полностью реализованы: ходы всех фигур, взятия, шах, мат, пат, рокировка
(короткая и длинная), превращение пешки (с выбором фигуры), взятие на
проходе, ничьи (пат, недостаточно материала, троекратное повторение позиции,
правило 50 ходов). Движок проверен perft-тестом на стартовой позиции
(значения 20 / 400 / 8902 / 197281 для глубин 1–4 совпадают с эталонными).

## Проверено

- Backend компилируется и запускается (`./mvnw spring-boot:run`).
- Frontend собирается (`npm run build`) и запускается в dev-режиме, доступен
  как по `localhost`, так и по LAN IP (проверено запуском на реальном сетевом
  интерфейсе).
- Главная страница открывается, поле имени работает, случайное имя
  присваивается при пустом поле.
- Игра с компьютером: выбор цвета, легальные ходы, ИИ отвечает с задержкой,
  нелегальные ходы отклоняются, партия корректно завершается (проверено
  автоматизированным браузерным тестом после рефакторинга сетевой игры).
- Сетевая игра проверена end-to-end двумя независимыми клиентами (реальные
  два браузерных контекста Playwright + отдельное тестирование
  WebSocket-протокола на уровне сообщений): оба видят друг друга в lobby,
  приглашение/принятие/отклонение/отмена, автоматический переход в общую
  партию, случайное разное назначение цветов, обмен ходами в реальном
  времени, отклонение нелегальных ходов и ходов не в свою очередь, шах,
  мат корректно завершает партию, оба игрока возвращаются в lobby после
  завершения партии, отключение игрока во время партии уведомляет соперника
  («Соперник отключился») после ~10-секундного окна на переподключение,
  переподключение с тем же `clientId` в течение этого окна восстанавливает
  партию без потери состояния.
